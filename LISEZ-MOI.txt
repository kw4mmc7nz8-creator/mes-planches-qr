MonCongélo — Version 3 (version de test)

CONTENU
- index.html : application
- qr-generator.html : générateur de planches QR (30 codes par feuille A4)
- icon-192.png, icon-180.png, icon-512.png : icônes sans texte, congélateur orange-rouge
- manifest.json : configuration de l’application web installable
- sw.js : cache hors ligne

MISE À JOUR SUR GITHUB PAGES
1. Faites une copie de sécurité de votre dépôt actuel.
2. Décompressez cette archive.
3. Envoyez le contenu du dossier MonCongelo à la racine du dépôt GitHub, en remplaçant les fichiers de même nom.
4. Vérifiez que index.html se trouve à la racine publiée, avec qr-generator.html, manifest.json, sw.js et les trois icônes.
5. Attendez le déploiement GitHub Pages. Fermez puis rouvrez Safari et rechargez le site. Si l’ancienne version reste affichée, supprimez le raccourci de l’écran d’accueil et ajoutez-le de nouveau après avoir vérifié le site dans Safari.

DONNÉES
La version conserve le nom de la base IndexedDB de la version précédente pour retrouver les fiches locales. Par précaution, exportez une sauvegarde avant la mise à jour. Les données locales sont associées à l’adresse du site et au navigateur.

CAMÉRA
Le scan nécessite une adresse HTTPS, Safari et l’autorisation d’accès à la caméra.
